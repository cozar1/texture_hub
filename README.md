# Texture Hub

Texture Hub is a small web application built for an assignment to organize and showcase texture assets. It provides a simple, focused interface for managing and previewing game art textures.

What the site does:

- Browse texture assets with image previews and basic metadata.
- View individual texture pages with details and a larger preview.
- Upload new textures and Aseprite files via the upload interface.
- Create and view collections of related textures.
- Simple user/profile pages for viewing owned or submitted textures.
- Uses lightweight templates to present texture galleries and single-item pages.

The repository contains the application entrypoint (`app.py`), HTML templates under `templates/`, and static assets under `static/`.
